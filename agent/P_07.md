# P_07 — Replace DSH web search

**Gate:** P_06 green **and** contract v1 untouched through dogfood.

## Steps

1. Map the DSH built-in tool's name, args and result shape onto v1 (prepared in P_03). Write the alias tool (e.g. `web_search`) as a thin wrapper over the same core.
2. Profile: disable the DSH web-search plugin, enable the alias. Make sure no two tools share a name (registration collision).
3. Re-run ~5 general, non-mission chats that used DSH web search before. Results should be equal or better and come back within budget.
4. **Rollback:** a single profile toggle restores the DSH plugin.

## Risks

- DSH may expect behaviour we don't provide (page content, not just URLs). Check in P_03, not here.
- Upstream DSH could rename or reshape its tool. Our alias owns the name only in our profile.
